# MXQ 4K → Linux VPN-шлюз

Превращение бюджетной ТВ-приставки (Rockchip RK3229, NAND, плата XT-MX4N-V03) в прозрачный VPN-шлюз для домашней сети.

**Что это даёт:** любое устройство (телефон, ТВ, компьютер) может пустить весь свой трафик через VPN одним действием — указав шлюзом IP приставки. Никаких приложений и настроек прокси на самом устройстве. Российские сервисы (Яндекс.Музыка, банки, маркетплейсы) идут напрямую с полной скоростью, заблокированные — через VPN.

## Возможности

- **Два режима:** «весь трафик через VPN» (кроме RU-сервисов и RU-IP) и «обход» (через VPN только заблокированное).
- **Категории с отдельным сервером:** Gemini/AI (включая Antigravity Google), игры (Roblox, Supercell, Garena, HoYoverse), YouTube — каждая категория через свой сервер с лучшим пингом, выбор в веб-панели.
- **Автообновляемые списки блокировок:** реестр РКН (~83 000 доменов) + сервисы, сами ушедшие из РФ (SoundCloud, Netflix и т.д.), обновление раз в час.
- **Hysteria2:** через sing-box-сайдкар (xray не умеет hysteria2) — hysteria-серверы из подписки доступны в общем пуле.
- **DoT-DNS:** провайдер не может душить DNS (симптом «Wi-Fi есть, интернета нет»).
- **Веб-панель** (порт 8080): подписки (Happ/Remnawape/vless-ссылки), пинг всех серверов, кнопка обновления, вкл/выкл VPN.

## Быстрый старт

Полная пошаговая установка «с нуля» — в **[docs/УСТАНОВКА.md](docs/УСТАНОВКА.md)**: прошивка NAND через Multitool (с учётом FTL-заголовка NAND), настройка Armbian, xray, DNS, шлюз, подключение устройств, траблшутинг.

- `docs/ИНСТРУКЦИЯ.md` — историческая инструкция по перепрошивке.
- `docs/NOTES.md` — технические заметки: архитектура, подводные камни железа (maskrom, NAND, драйвер Wi-Fi), особенности прошивки.
- `files/` — все скрипты и конфиги, готовые к копированию на приставку.

## Железо

ТВ-приставка MXQ 4K / RK3229 / NAND 8 ГБ / кабель 100 Мбит. Wi-Fi-чип SSV6051P драйвером не поддерживается — приставка работает строго по кабелю.

Пароли, токены подписок и идентификаторы в документах заменены плейсхолдерами.
